# THUNDER TITANS – OFFICIAL SPORTS CLUB WEBSITE
### Silimpur, Tangail, Dhaka, Bangladesh • Established 2011

An international-grade, cinematic sports club website built for **THUNDER TITANS**, a community-driven sports club formed by the youth of Silimpur village, Tangail, Bangladesh.

---

## 🌐 Website Architecture & Sections

1. **Navigation Bar**: Transparent over hero with auto-switching solid dark blur backdrop on scroll, active section highlighter, responsive mobile menu drawer, and "JOIN THE CLUB" quick action button.
2. **Cinematic Hero Section**: High-impact stadium photography background, dark gradient vignette, bold condensed typography (`Bebas Neue` & `Oswald`), official badge (`EST. 2011 | SILIMPUR, BANGLADESH`), action buttons, and official crest card.
3. **About Our Club**: Narrative of Thunder Titans' founding in 2011, mission, vision, 5 core pillars (*Community Unity, Teamwork, Discipline, Sportsmanship, Youth Development*), paired with the authentic team celebration photograph (`ice_1.jpeg`).
4. **Our Sports**: Dedicated cards for **01. Cricket**, **02. Football**, and **03. Badminton**, featuring interactive "Explore More" modals with training schedules, ground details, and key competencies.
5. **Championships & Tournaments**: Authentic showcase of club participation in Tangail district and village tournaments, featuring the Tangail championship trophy (`ice_2.jpeg`), field victory photo (`ice_1.jpeg`), and promotional badge (`mail.jpeg`).
6. **Club Gallery**: Responsive asymmetrical grid with category filters (*All, Authentic Club Assets, Sports Action*) and an interactive full-screen Lightbox modal with keyboard navigation (Escape, Left, Right).
7. **Join Our Club – CTA**: High-energy orange-and-black call-to-action driving inquiries to the club.
8. **Contact Section**: Complete official information including clickable phone (`tel:01748418680`), direct links to Facebook and Instagram, location in Silimpur, Tangail, and an interactive join/inquiry form.
9. **Main Footer**: Club summary, navigation links, sports list, official headquarters, social links, and copyright notice.
10. **Developer Credit (Bottom of Footer)**: Elegant credit line centered at the very bottom:
    - `"Designed & Developed by Binoy"`
    - Clickable link to [Binoy's LinkedIn Profile](https://www.linkedin.com/in/binoysarker2003/) with `target="_blank"`, `rel="noopener noreferrer"`, LinkedIn icon, and hover animation.

## 🛠 Tech Stack

- **Framework:** React 18 + Vite 5
- **Styling:** Tailwind CSS with custom theme extensions
- **Icons:** Lucide React
- **Typography:** Bebas Neue, Oswald, and Inter via Google Fonts

## 🚀 Running the Project

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
